# V1 推理引擎范围与后续工作

EmbodiInfer 负责模型执行、批处理、调度和服务协议；EmbodiRun 负责设备、任务、动作执行和部署生命周期。两者通过公开服务协议连接，不把机器人控制逻辑放进推理引擎。

## 已落地

- RTC 与 VLASH 异步推理接口和服务接入。
- π0.5 跨会话 batch 说明：默认 batch 为 1，可通过 `--max-batch` 开启。
- 模型、服务、性能和双语文档入口。
- CUDA、checkpoint 和模型专属验证保持显式标记；测试跳过不等于模型验证通过。

## 仍待补充

- Jetson AGX、Jetson Thor、4090 等设备上的统一原始 benchmark。
- π0.5、ActiveVLN 及其他模型的算子优化结果和可复现实验条件。
- 面向新硬件/新模型的硬件信息采集、候选检索、算子建议和报告生成工具。
- 与 EmbodiRun 的部署成本、资源占用和多机扩展数据对照。

这些项目属于路线图，不在没有 checkpoint、硬件和原始数据时虚构性能结论。
